# ChartPilot

AI-powered chart analysis platform.

## MVP
- Responsive dashboard and chart analyzer UI
- Timeframes: 5M, 10M, 15M, 30M, 1H, 4H
- Structured setup output: entry, stop loss, take profit, bullish/bearish scenarios
- Pricing: ₹249 / ₹499 / ₹999

Current version includes a frontend demo analysis. Live AI, authentication, database, market data and payments will be connected in later phases.
